# Contributing to nimproj

First off, thank you for your interest in contributing!

**Reporting issues** — please open a [GitHub issue](https://github.com/JohnMoutafis/nimproj/issues/new).

**Changelog** — see [CHANGELOG.md](CHANGELOG.md) for a record of all notable changes.

Detailed contributor docs live in `docs/contributing/`:

- [Development Setup](docs/contributing/setup.md) — toolchain, PROJ, supported platforms
- [Testing & CI Policy](docs/contributing/testing.md) — local test commands, the differential-fixture rule, the merge gate
- [Code Style](docs/contributing/code-style.md) — Nim style, the PROJ binding rules
- [Release Process](docs/contributing/release-process.md) — maintainer release checklist

*Thank you for helping make nimproj better!*
